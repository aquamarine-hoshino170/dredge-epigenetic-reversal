# Contributing to DREDGE

We welcome contributions to the DREDGE computational framework.

## Guidelines
1. Fork the repository and create your branch from `main`.
2. Ensure any new molecular screening functions adhere to Lipinski's Rule of 5.
3. Test all PyTorch models and Vina scoring pipelines locally before opening a Pull Request.
4. Open an issue first to discuss substantial algorithmic or target additions.
