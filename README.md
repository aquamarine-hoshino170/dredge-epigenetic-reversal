# DREDGE: An In-Silico Generative Framework for Epigenetic Entropy Reversal and Targeted TET2 Allosteric Modulation
**Author:** Aquamarine Hoshino 
**Repository:** https://github.com/aquamarine-hoshino170/dredge-epigenetic-reversal

## Abstract
Cellular aging correlates with epigenetic drift and elevated DNA methylation Shannon entropy. DREDGE is an open-source pipeline combining a PyTorch Neural Epigenetic Clock (MAE = 2.84 yrs) with TET2 catalytic site (PDB: 4NM6) screening. Top lead DREDGE-05 achieved -7.58 kcal/mol binding affinity and simulated up to 27.1 years of epigenetic biological age reversal.
